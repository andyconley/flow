# flow-plan

Use for shaping work before implementation starts.

Use this command to:

- turn an idea, bug, or request into an implementation-ready work item
- define scope boundaries
- name required UI states when UI is involved
- define validation expectations
- choose whether the work belongs in scout mode or gated implementation

Output of a good plan:

1. problem statement
2. desired outcome
3. in-scope and out-of-scope items
4. required states when UI is involved
5. Storybook or design-contract expectations when UI is involved
6. validation expectations
7. recommendation: `/flow-scout` or `/flow-implement`

If the work cannot be understood without chat history, the plan is not done yet.
