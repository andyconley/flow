# flow-boot

Orient to the project before planning or implementation work.

Read at minimum:

- `.flow/FRAMEWORK.md`
- `.flow/PROJECT.md`
- `.flow/memory/STATE.md`
- `.flow/memory/DECISIONS.md`

Check for interrupted work in `.flow/runs/`.

Use this command:

- at the start of a session
- before resuming interrupted work
- when context feels stale or ambiguous

Boot should identify:

- the current project and runtime context
- active standards and project overlays that matter
- active or interrupted work
- any important memory caveats or blockers

Return:

1. current orientation
2. active or interrupted work, if any
3. which files are the current durable sources of truth
4. next recommended command
