# Requirements: Review Provenance Core

Implement the approved review-only, append-only orchestration amendment mechanism from `review-provenance-refinement-2` and codify the three planning/bootstrap failures that occurred before provider execution:

1. `approve-definition` validates canonical `shaper-intent.json` before writing approval state or digests.
2. A Delivery-Lead-intended plan is rejected before implementation unless its manifest and linked job charter define an executable manager, bounded producer/verifier roster, provider/model bindings, safe targeted test, and isolated pinned worker-worktree contract.
3. Definition or plan approval rejects a Delivery envelope whose runtime or Magentic limits exceed protocol-v8 runner bounds.

The original Delivery manifest and approved digests remain immutable. The review overlay is limited to verification corrections and appended read-only reviewers. Provider-adapter repairs, application to `maf-runtime-readiness-2`, general artifact editing, multiple amendment generations, macOS baseline repair, and MAF redesign are excluded from this slice.
