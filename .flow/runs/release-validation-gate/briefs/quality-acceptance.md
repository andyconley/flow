# Assignment Brief: Quality Acceptance

- Role: independent quality reviewer
- Provider: `/root/release_gate_quality`
- Task: judge the implemented result against the original requirements and all fourteen acceptance criteria, with evidence per criterion and actionable findings.
- Evidence inventory: the approved requirements, acceptance criteria, plan, validation plan, implementation evidence, changed workflow/helpers/tests/docs, and all role reviews are the expected evidence set.
- Search method: inspect each named artifact and the complete branch diff; cite paths for coverage and state where a required behavior is genuinely absent.
- Constraint: read-only repository review; record the verdict in `review/quality-review.md`.
