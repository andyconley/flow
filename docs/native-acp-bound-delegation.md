# Native ACP bound role delegation

Native ACP receives stdio MCP servers, but Goose built-in Summon is not an advertised native-client tool. Local-profile delivery therefore attaches a per-operation MCP capability owned by Flow's existing operator. The implementation capability starts only the approved, digest-pinned lead-developer; the review capability starts only the bound private-Claude quality-reviewer. Each accepts no task, command, path, provider or model overrides. Calls are idempotent and status polling does not start another worker. Existing non-native Summon delivery is unchanged.

The stdio client uses the native sandbox's existing Unix-socket permission and an operator-owned 0700 temporary directory/0600 socket. No sandbox rules are added. The operator retains the same role-execution authority as its prior Summon path; this is a bounded delegation capability, not a generic host shell. Worker context/output/compaction remain frozen. Native review keeps private configuration and its existing sandbox/wrappers. The native client cannot change the bound recipe or caller inputs. Operator evidence records worker PID/identity and result. A prior running delegation blocks a new operation until reconciled; operator cleanup cancels owned workers and removes its socket.

Coordinator completion is rejected unless its required delegate completed and the candidate still matches the delegate result. The coordinator cannot override an independent review's non-approval. Independent Flow tests and candidate acceptance remain separate.

The knowledge stdio entrypoint loads the explicitly permitted `poc` package directly, avoiding Python package discovery through a denied parent directory. Its engine, read-only tools, and sandbox grants are unchanged. Because transport code participates in the existing snapshot contract, qualification uses an isolated knowledge copy rebuilt under candidate code rather than modifying production notes or bypassing snapshot validation.

Regression coverage exercises MCP discovery/calls over actual stdio/Unix transport, override rejection, one-operation idempotence, uncertain-prior fail-closed behavior, fixed local/native provider settings, and Python package startup when its parent directory is denied. A live qualification must additionally prove native tool calls, real Qwen execution, independent tests, private review and retrieval use. The separate default `chatgpt_codex` OAuth-cache mismatch is not fixed by this change.
