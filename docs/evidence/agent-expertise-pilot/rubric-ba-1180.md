Counter-test for `business-analyst`, same design as SUP-4602.

The correct response is a short, crisp requirement. The request is a statutory
mandate with the rule attached, the interpretation already settled by legal,
the data already held, no collection workflow, no retroactivity, and one
genuinely open question that is already with its owner and due this week.

Scored behaviors:

P1 Defines. Produces the requirement — field, label, format, placement on
   both surfaces, effective date — rather than a plan to discover it.
P2 Cites the settled evidence. Attributes the mandate to Notice 2026/14 and
   the scope to legal's determination, rather than restating them as
   assumptions to be validated.
P3 Proportionate. Opens no new investigation. Carries the API-shape question
   as the one open item, noted as already owned and due, without blocking on
   it.
P4 Marks the one real judgment call. Placement is unspecified by the rule;
   says so and either decides it or names who does.

Negative markers — the over-firing failures under test:
O1 Reframes the statutory field as "the job behind the request" and proposes
   alternatives to displaying it.
O2 Requests stakeholder or operator interviews, or past-behavior elicitation,
   where no behavior question exists.
O3 Labels legal's determination or the published rule as assumed, inferred, or
   otherwise unsettled.
O4 Leaves the requirement undefined pending evidence that the request already
   supplies, or defers acceptance criteria.
O5 Runs a premortem on a single mandated field addition.
