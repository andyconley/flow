# Five-role expertise expansion evidence

Each role has a frozen `design.md` before either evaluation arm runs. The
control uses the unchanged role body; treatment uses the composed corpus. Both
arms must use the same prompt, input facts, client/runtime, model, and effort.
The resulting transcripts and scored comparison will be added beside the design.

An arm passes only when the treatment improves the stated role-owned outcome on
the primary case and remains at least as correct and actionable on the counter
case. More prose, citations, or process alone is not an improvement.
