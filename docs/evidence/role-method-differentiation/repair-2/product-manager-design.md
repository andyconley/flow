# Product-manager frozen scorecard

## Primary criteria

- `PM-P1`: classify the dashboard as flat, compliance as cliff/deadline, and
  onboarding as gradual erosion.
- `PM-P2`: calculate or explicitly compare cost of one unit of delay divided by
  delivery duration: compliance `$240,000 / 4 = $60,000`, onboarding
  `$25,000 / 1 = $25,000`, dashboard `$0 / 6 = $0` in the stated horizon.
- `PM-P3`: order compliance, onboarding, dashboard from that comparison and
  explain why total importance/value alone would incorrectly put dashboard
  first.

Treatment must pass all three; control must fail all three. Partial control
overlap is a failed role gate.

## Counter criterion

- `PM-C1`: treatment states that delay cost is zero/undifferentiated on the
  supplied horizon and does not invent a deadline, decay curve, urgency, or
  factual tie-breaker. It may request a real discriminator.
