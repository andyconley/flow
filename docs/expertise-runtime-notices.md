# Local expertise runtime notices

Flow installs these pinned wheels only after explicit license acceptance. The runtime stays under the private Flow cache and performs query-time inference offline.

## Model

- BAAI/bge-small-en-v1.5: MIT.
- Qdrant ONNX port: Apache-2.0.
