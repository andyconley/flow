# Implementation interface v1
Snapshot has schema_version=1, kind="snapshot", source={digest,revision,files:[{path,sha256}]}, config, config_digest, graph, quality, gaps, artifacts, sources. Graph has nodes,edges,unresolved,inventory. Nodes: id="python:"+flat module name, label, parent="component:cli", path, sha256, language. Edges: id (deterministic string), from, to, kind="direct-import", sources=[{path,start_line,end_line}]. Graph inventory: [{path,status,reason}], unresolved: [{path,reason,...}]. Sources: relative path -> {sha256,lines:[text without newlines]}. Quality: {status:"available"|"inconclusive"|"unsupported",records:[],gaps:[],...}. Quality record has id, path, symbol, source_sha256, complexity, coverage, crap, mutation. Packet: schema_version=1,kind="packet",baseline: snapshot,candidate:snapshot,delta:{added_edges,removed_edges,unchanged_edges,new_cycles,baseline_cycles},policy:{...},policy_result,overall_result,findings:[],gaps:[],approval,artifacts. All edge arrays contain edge dicts. Finding: {id,kind,message,edges:[edge ids],...}. Root owns model/snapshot/CLI/policy/delta and integration; collaborators own explicit files only. Do not change this contract without messaging root.
