# flow-archive

Archive only after accepted review. Record useful project memory, capability
gaps, outcomes and unresolved follow-up, then close the workflow:

```sh
flow workflow archive <work-id> --disposition memory=<value> --disposition capability_gaps=<value>
```

Flow's run artifacts and archive retrieval remain the project record. SDK
conversation histories remain runtime evidence. Do not convert old checkpoints,
start providers, merge, deploy or modify other worktrees as part of archive.
Historical runs can still use their existing archive commands and records.

Use the active runtime memory provider as companion context when available.
Verify material claims against canonical project artifacts and code.
