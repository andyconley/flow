# Expertise sources

The works cited by expertise entries, one record per work. Entries reference a
work by its id and carry their own pinpoint; see ADR 0008.

An entry's `Source:` line names one or more ids, each with an optional
parenthesised locator:

```
- Source: cook-how-complex-systems-fail (thesis 8); allspaw-blameless-postmortems
```

Ids are stable. Renaming one breaks every entry that cites it.

## allspaw-blameless-postmortems

- Author: John Allspaw
- Title: "Blameless PostMortems and a Just Culture"
- Published: Etsy Code as Craft, 2012
- URL: https://www.etsy.com/codeascraft/blameless-postmortems-and-a-just-culture/
